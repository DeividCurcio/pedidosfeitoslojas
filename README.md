# Pedidos da loja

Painel estático e responsivo para registrar pedidos no navegador. Não exige instalação de dependências nem servidor: abra `index.html` localmente ou publique a raiz do repositório pelo GitHub Pages.

## Publicar no GitHub Pages

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch `main` e a pasta `/ (root)` e salve.
4. Aguarde a publicação e abra a URL mostrada nessa tela. Se o Pages já estiver configurado para `main`, incorpore esta alteração à `main` antes de esperar que o site atualize.

Os pedidos são salvos em `localStorage` no próprio navegador e não são sincronizados entre dispositivos ou usuários. Não use para guardar informações sensíveis.
